Installez l'application CNH SERVICE

Retrouvez rapidement nos services, vos réservations et toutes les informations CNH SERVICE directement depuis votre téléphone.

Sur iPhone ou iPad

Installation via Safari — 30 secondes

1

Ouvrez cnhservices.vercel.app dans Safari.

2

Appuyez sur le bouton Partager (le carré avec une flèche vers le haut, en bas de l'écran).

3

Faites défiler et sélectionnez « Sur l'écran d'accueil ».

4

Activez « Ouvrir comme application » si l'option est proposée (iOS 18+).

5

Appuyez sur « Ajouter » — l'icône CNH Service apparaît sur votre écran d'accueil.

Sur Android

Chrome, Edge, Samsung Internet…

1

Appuyez sur le bouton ci-dessous : l'installation démarre automatiquement.

2

Si le bouton est grisé : menu ⋮ du navigateur → « Ajouter à l'écran d'accueil » → Installer.

✓ CNH SERVICE est déjà installé sur votre téléphone.

Sur ordinateur

Chrome / Edge — desktop

1

Cliquez sur l'icône ⊕ (Installer) dans la barre d'adresse du navigateur.

2

Ou menu ⋮ → « Installer CNH Service… ».
